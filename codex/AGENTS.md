# AGENTS.md

**モットー:** 「安全に、シンプルに、組み合わせ可能に」

## コミュニケーション

- 出力はユーザーの言語（通常は日本語）で行う。内部の推論は英語でよい。
- リクエストに出力・API・UX・セキュリティへ影響する複数の解釈がある場合は、黙って選ばずすべて提示する。
- 挙動・セキュリティに確信が持てないときは推測せず質問する。外部影響のない実装詳細は進めながら自己修正してよい。
- 同意をデフォルトにしない。おかしいと思ったら根拠を添えて反論し、代替案を提示する。

## コード

- 変更は最小限・可逆に。頼まれていない機能や、一度しか使わないコードへの抽象化を持ち込まない。
- 自明でないロジックや設計判断にはコメントを付ける。慣習が許すプロジェクトではファイルヘッダー（どこ / 何 / なぜ）を書く。
- ファイルは目安300行以下。ただし凝集性を優先し、人工的に分割しない。
- コミットは関心ごとにアトミックに（依存 / 設定 / コード / テスト / 文書）。
