# Grok CLI ヘルパー

このスキルは、Grok CLI（xAI の Grok Build）を使用して、コードや設計についてセカンドオピニオンを得たり、レビューを依頼したりするためのものです。

## 使用場面

1. **文言・メッセージの検討** - エラーメッセージやUIテキストの改善
2. **コードレビュー** - 実装のレビューや改善提案
3. **設計の相談** - アーキテクチャやAPI設計のアドバイス
4. **バグ調査** - 問題の原因特定や解決策の提案
5. **最新情報の調査** - Grok は Web 検索を標準で使えるため、最新動向の確認にも向く

## 実行方法

読み取りのみ（レビュー・調査）:

```bash
grok -p "<リクエスト内容>" --cwd "$PWD"
```

ヘッドレスモード（`-p`）では編集系ツールの承認プロンプトに応答できないため、デフォルト権限のままなら実質的に読み取り専用で動作する。

ファイル書き込みあり（実装・修正）:

```bash
grok -p "<リクエスト内容>" --cwd "$PWD" --permission-mode acceptEdits
```

## 使用例

### コードレビューを依頼

```bash
grok -p "src/auth.tsのコードをレビューして、改善点があれば教えてください" --cwd "$PWD"
```

### 設計相談

```bash
grok -p "認証システムをJWTからセッションベースに変更する場合の影響範囲を分析してください" --cwd "$PWD"
```

### 最新情報の調査

```bash
grok -p "ライブラリXの最新バージョンの破壊的変更を調べてください" --cwd "$PWD"
```

## オプション

- `-p, --single <PROMPT>`: 単発実行。応答を stdout に出力して終了（ヘッドレスモード）
- `--cwd <dir>`: 作業ディレクトリを指定
- `--permission-mode <mode>`: 権限モード（`default` / `acceptEdits` / `plan` / `bypassPermissions` など）
- `-m, --model <MODEL>`: モデル指定（省略時はデフォルト）
- `--max-turns <N>`: エージェントターン数の上限（暴走防止に有効）
- `--disable-web-search`: Web 検索を無効化

## 注意事項

- 事前に `grok login` での認証が必要（未認証だとエラーになる）
- 結果はセカンドオピニオンとして参考にし、最終判断はユーザーが行ってください
- 長時間かかる場合はバックグラウンド実行を検討する
