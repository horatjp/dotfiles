# INDEX — docs/ai/ の地図

セッション開始時にまずこのファイルと STATUS.md を読む。
ファイルを追加・移動・アーカイブしたAIは、このINDEXを即時更新すること。

| パス | 内容 | いつ読むか |
|---|---|---|
| STATUS.md | 現在地。進行中の作業・次の一手 | 毎セッション開始時(必読) |
| learnings.md | 失敗と学び(再発防止) | 毎セッション開始時(必読) |
| PROJECT.md | プロジェクト概要・技術スタック・制約 | 初回参加時、前提を確認するとき |
| RULES.md | 書き込みルール・命名規則・テンプレート | docs/ai/ に書き込む前 |
| decisions/ | 意思決定の記録(重要度はフロントマターの impact) | 過去の判断・経緯を確認するとき |
| research/ | 技術調査・バグ解決の記録 | 関連トピックに着手するとき |
| references/ | 一次資料・URL | 出典を確認するとき |
| archive/ | 廃止ファイルの退避先 | 通常は読まない |
