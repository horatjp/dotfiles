# 取り込みメモ: onewave-ai/claude-skills @ screenshot-to-code

- 出典: https://github.com/onewave-ai/claude-skills （screenshot-to-code/SKILL.md、131行）
- 目的: UIスクリーンショットをHTML/CSS/React/Vueの動くコードに変換する

## 良い点・転用ポイント

1. **分析→フレームワーク決定→生成→レスポンシブ化→納品** の5ステップ構造が明快
2. **分析の観点を列挙**: レイアウト構造（grid/flex）、コンポーネント種別、視覚詳細（色・フォント・余白・影・角丸）、レスポンシブの手がかり
3. **デフォルトを宣言**: フレームワーク未指定なら「モダンならReact+Tailwind、シンプルならプレーンHTML/CSS」— 質問で止まらない
4. **再現の厳密性要件**: 色はhexを抽出して正確に一致させる、比率・余白を可能な限り一致、セマンティックHTML必須、a11y属性（alt/ARIA）必須
5. **レスポンシブの具体的手段**: rem/em/%/vw、clamp()/min()/max() での流体タイポ
6. **納品物の定義**: 全ファイル+ファイル構成の説明+実行手順+設計判断のメモ、まで含めて「完了」

## 教訓

- 参照画像がある場合のワークフロー（観察の観点リスト→忠実再現の基準）はWEBサイト作成スキルの1分岐として取り込める
- 「デフォルト技術スタックの宣言」は、毎回ユーザーに聞き返さないための実務的な工夫
