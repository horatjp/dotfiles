# learnings.md 棚卸し手順(月次実行)

各ロールの `roles/*/learnings.md` を月次で整理するための指示書です。
Claude Code等のエージェントに、以下の内容をそのままプロンプトとして渡して実行させます。

## 実行内容

1. `roles/*/learnings.md` を全て読み込む
2. 各ファイルについて:
   - 重複している内容を1つに統合する
   - 矛盾している記述は新しい日付を優先し、古い方を削除する
   - 3ヶ月以上前で、その後の運用でも同じ問題が再発していないものは
     `learnings-archive.md`(同ディレクトリ)に移動する
3. 各ロールの `ROLE.md` frontmatter の `last_used` を確認し、3ヶ月以上前
   (または空)のロールを「整理候補」として一覧化する
4. 変更をブランチにまとめて **Pull Request を作成**し、変更点の要約を本文に書く
   (learnings の統合・削除も誤りうるため、直接 main に commit しない。
   人間がレビューして merge する)
5. ロール自体の削除・統合は提案までに留める(最終判断は必ず人間が行う)

## 注意事項

- `ROLE.md` の本文(役割定義)は書き換えないこと。対象は learnings.md の整理と、
  frontmatter `last_used` の確認のみ
- 「使われていないロール」の削除は自動化しない。判断ミスのコストが高いため
  人間の確認を必須とする
