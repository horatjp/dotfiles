# deploy-checklist

## 使用タイミング
fan-in(統合)タスクの完了時、または本番デプロイ前に必ず実行する。

## チェック項目

- [ ] 全テストが通っている
- [ ] code-review Skillでの指摘が解消されている
- [ ] 環境変数・秘密情報がコードにハードコードされていない
- [ ] DBマイグレーションがある場合、ロールバック手順が用意されている
- [ ] 破壊的変更がある場合、影響範囲がIssueに明記され人間の承認を得ている
- [ ] ログ出力に個人情報・機密情報が含まれていない

## 判定

全項目クリアで初めてマージ/デプロイの実行に進む。1つでも未達なら差し戻す。

## learnings/
過去のデプロイ事故・ヒヤリハットを `learnings/` に1エントリ1ファイルで蓄積する
(書式は `learnings/README.md` 参照)。
