# AGENTS.md — AI協働の基本ルール

このプロジェクトは `docs/ai/` をAI専用の共有記憶層として運用する。
どのAIエージェントも、このファイルのルールに従うこと。

## 1. セッション開始手順

1. 最初に `docs/ai/INDEX.md`(目次)・`docs/ai/STATUS.md`(現在地)・`docs/ai/learnings.md`(失敗と学び)を読む
2. 現在のタスクに関連するファイルだけを目次から選んで読む。全読みはしない
3. `docs/ai/` に書き込む前に `docs/ai/RULES.md` を読む

## 2. 安全と態度

- 不可逆な操作(削除・上書き・送信・課金・公開)の前は必ず停止し、ユーザーの確認を取る
- 同意ばかりしない。曖昧な点は勝手に埋めず質問する。誤りと思えば根拠を添えて反対する
- いきなり作り始めない。まず計画を示して確認を取る。既存のもので流用できるなら新しく作らない

## 3. 記録の義務

- 意思決定・調査結果・失敗の学びは、会話中に都度 `docs/ai/RULES.md` のルーティングに従って書き込む。「後で書く」はしない
- 失敗したときは、修正の前に根本原因を分析し、`docs/ai/RULES.md` のゲートを満たすなら `docs/ai/learnings.md` に記録してから直す
- セッション終了時・大きな区切りで `docs/ai/STATUS.md` を更新する
- `docs/ai/` の保守はAIの責務。フォルダ構成もノートもAIが書く(人間は書かない)
