# 実装語彙集(スタイル別のヒント)

このファイルは方向性を「選ぶ」ためのメニューではない。仮説の導出はSKILL.md手順4(戦略→骨格→トークン→シグネチャー→固有名)で行い、その実装を具体化する段階で、性格の近い項を辞書的に参照する。複数の項の掛け合わせや、ここにない表現を作ることを常に優先してよい。案の名前にここの見出し(「ボールド」等)をそのまま使わないこと。

## ミニマル / コーポレート

- 配色: 白〜オフホワイト基調 + アクセント1色(ブランドカラー)。彩度は抑えめ
- タイポグラフィ: サンセリフ中心、ウェイトの差でメリハリをつける。装飾は最小限
- 余白: 広め。要素数を絞り、余白そのものを高級感の演出に使う
- 画像: プロダクト写真やオフィス写真は加工少なめ、正直な見せ方
- 向いている業種: BtoB、士業、コンサル、SaaS、金融
- 実装のヒント: 見出しにGoogle Fontsの`Inter`や`Noto Sans JP`、本文も同系統で統一。背景は`slate-50`や`gray-50`、アクセントはブランドカラー1色を`600`〜`700`の濃さで使うと締まる

## パステル / フレンドリー

- 配色: 淡いパステルカラーを2〜3色使い、彩度低めで統一感を出す
- タイポグラフィ: 丸みのあるフォント、見出しはやや大きめでポップに
- 余白: 角丸・柔らかい影を積極的に使う
- 画像: 人物写真は自然光・カジュアルな雰囲気。イラスト調にしたい場合はユーザー提供かライセンス明確な実素材が前提(実行AIが描いて代替しない)
- 向いている業種: 店舗、教育、子育て・美容系、地域密着ビジネス
- 実装のヒント: 見出しに`Zen Maru Gothic`や`M PLUS Rounded 1c`などの丸ゴシック系。背景は`rose-50`や`amber-50`などの淡色、カードは`rounded-2xl`+薄い`shadow`で柔らかさを出す

## ダーク / プレミアム

- 配色: ダーク基調(黒〜濃紺〜チャコール) + ゴールドや差し色のアクセント1色
- タイポグラフィ: セリフ or 洗練されたサンセリフ、字間を広めに取り高級感を演出
- 余白: 大胆な余白とグリッド、写真を大きく見せる
- 画像: 高コントラスト・シネマティックな写真
- 向いている業種: 高級ブランド、飲食(高価格帯)、不動産、美容医療
- 実装のヒント: 見出しに`Playfair Display`や`Noto Serif JP`、本文はサンセリフで対比を作る。背景は`neutral-900`〜`black`、アクセントは`amber-400`〜`yellow-600`系を控えめに一箇所だけ使う

## エディトリアル / タイポグラフィ主導

- 配色: モノトーン中心、写真や図解が主役になるよう配色は脇役に徹する
- タイポグラフィ: 大胆な見出しサイズ、雑誌のようなグリッドレイアウト
- 余白: 非対称なレイアウト、あえて崩したグリッド
- 画像: 大きく使う。テキストと画像の重なりなど雑誌的な表現
- 向いている業種: メディア、クリエイティブ系、採用サイト、ブランドストーリー訴求
- 実装のヒント: 見出しに極太のディスプレイフォント(`Zen Kaku Gothic New`の太字など)を大きめのサイズで使用。グリッドはTailwindの`grid`+非対称な`col-span`で崩し、余白は`gap`を大きめに取る

## ボールド / ハイコントラスト

- 配色: 原色に近いビビッドな配色、白黒との強いコントラスト
- タイポグラフィ: 極太のディスプレイフォント、大きな文字で言い切る
- 余白: メリハリ重視、要素間の差を大きく
- 画像: 少なめ、代わりにタイポグラフィと色面で魅せる
- 向いている業種: スタートアップ、イベント、スポーツ・フィットネス、若年層向けD2C
- 実装のヒント: 見出しに`Archivo Black`や太字の`Noto Sans JP`を大サイズで。ビビッドな1〜2色(例: `orange-500`と`black`)を色面としてブロック単位で使い、中間色を極力使わない

## ナチュラル / 温かみ

- 配色: アースカラー・ベージュ・テラコッタなど自然由来の色調
- タイポグラフィ: 手書き風アクセントや柔らかいセリフとの組み合わせ
- 余白: オーガニックな曲線の区切り(CSSで表現)
- 画像: 自然光・素材感のある写真、加工は最小限
- 向いている業種: 飲食、農業・食品、ウェルネス、手仕事系ブランド
- 実装のヒント: 見出しに`Shippori Mincho`などの柔らかいセリフ、背景は`stone-50`や`orange-50`のようなアーストーン。セクション区切りは大きな角丸や曲線(CSSの`border-radius`・`clip-path`)で有機的な印象を出せる

## テック / SaaSモダン

- 配色: 白ベース+ダークネイビーの文字、彩度高めのアクセント1色。またはダークベース+アクセント1色
- タイポグラフィ: 幾何学的な欧文サンセリフ(`Inter`、`Space Grotesk`など)+`Noto Sans JP`。数値・データを大きく見せる
- 余白: 機能・特徴の整理にベントーグリッド(大小のカードの組み合わせ)が有効。角丸の半径は全体で統一
- 画像: 写真より実プロダクトのUIスクリーンショットが主役(素材がなければFPOで「どの画面か」を指定する)
- 向いている業種: SaaS、ITサービス、スタートアップ、ツール・アプリ系
- 実装のヒント: グラデーションを使うなら1箇所の背景に留める。紫〜インディゴ系のデフォルト感が出ていないか、`design-principles.md`のアンチパターン一覧と必ず照合する

## 和モダン

- 配色: 生成り・墨・藍・抹茶・朱など、和の伝統色をベースに彩度を抑えて上品にまとめる
- タイポグラフィ: 明朝体を主役に。縦書きの短い見出しや、漢字1〜2文字を大きくあしらう表現も効く
- 余白: 「間」を意識した特に広い余白。要素数を絞り、詰め込まない
- 画像: 素材感(木・和紙・石・土)や手仕事のディテールが伝わる写真。余白を残した構図
- 向いている業種: 旅館・料亭・和菓子・工芸、寺社、鍼灸・整体、伝統を打ち出したい士業・老舗企業
- 実装のヒント: 見出しに`Shippori Mincho`や`Zen Old Mincho`、本文は細めの`Noto Sans JP`。縦書きは`writing-mode: vertical-rl`をアクセントとして一箇所だけに使う。背景は生成り(`stone-100`や`#f7f5f0`近辺)、罫線は墨色の1pxで繊細に

## 組み合わせの考え方

1つの項をそのまま使うのではなく、「ベースはミニマル/コーポレートの語彙、アクセントの扱いだけパステルから借りる」のような部分的な掛け合わせが基本。案どうしの差はSKILL.md手順4の分離ルール(骨格が異なる+明度帯/書体の性格/アクセント色相の2軸以上)で担保する——「配色だけ変えた同じレイアウト」の複数案にしないこと。
