# 取り込みメモ: anthropics/skills @ frontend-design

- 出典: https://github.com/anthropics/skills （skills/frontend-design、55行の簡潔なスキル）
- 目的: テンプレ的に見えないUIの視覚デザイン指針（美的方向性・タイポグラフィ・意図的な選択）

## 良い点・転用ポイント

1. **ロールプレイで品質基準を設定**:「唯一無二のビジュアルを作る小さなスタジオのデザインリード」として振る舞わせ、「テンプレ案は既に却下された」という文脈を与える
2. **主題に根ざす**: ブリーフが曖昧なら、具体的な主題・オーディエンス・ページの単一の役割を自分で決めて宣言してから設計する
3. **AI生成デザインの既知の定番3種を明示**して回避させる: ①クリーム背景+セリフ見出し+テラコッタ ②漆黒背景+アシッドグリーン/朱の単一アクセント ③新聞風の細罫線・角丸ゼロの高密度レイアウト
4. **2パス方式**: まず設計プラン（色4-6個の named hex / 書体2役以上 / レイアウト1文+ASCIIワイヤー / シグネチャー要素1つ）→ ブリーフと照合して自己批評 → それからコード
5. **大胆さは1箇所に集中**: シグネチャー要素1つを際立たせ、周囲は静かに保つ。「出かける前に鏡を見てアクセサリーを1つ外せ」（シャネル）
6. **品質フロアを黙って満たす**: モバイル対応・キーボードフォーカス・reduced motion
7. **UIコピーも設計素材**: 能動態、ユーザー視点の命名（「Save changes」であって「Submit」ではない）、エラーは謝らず原因と対処を示す
8. タイポグラフィがページの人格を担う。構造装置（番号・罫線・ラベル）は内容の真実を符号化するときだけ使う（01/02/03の番号は実際に順序が意味を持つときのみ）
