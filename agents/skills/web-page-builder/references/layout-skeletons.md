# レイアウト骨格カタログ（収束防止の母集団）

このファイルは`scripts/roll_layout.py`の抽選母集団であり、Step 1で骨格を決める際の語彙。Claudeは放っておくと毎回同じ骨格に収束する癖があるため、骨格は「思いつき」ではなくロールの出目を起点にする。各項目は起点であって檻ではない——出目を題材に合わせて変形するのが仕事。なお骨格はトップページの構成の型であって「LP」を意味しない。玄関化要件（SKILL.md Step 3）は、どの骨格にも重ねて適用する。

## ページ骨格

- **S01 縦一本ストーリー**: 導入→課題→解決→証拠→CTAを一本道で語る。迷わせない構成。初回接触の多い業種に
- **S02 グリッド即出し**: ヒーローを極小にし、最初のスクロールで商品・作品の一覧を見せる。モノが語る業種（EC・ギャラリー・施工例）に
- **S03 巨大タイポ・マニフェスト**: 宣言文が主役、写真は従。思想・人柄で選ばれる商売に
- **S04 フルブリード写真**: 画面いっぱいの1枚+下端に情報を寄せる。空気感が商品の業種（宿・飲食・美容）に
- **S05 分割スクリーン**: 左右50/50で対比を作る。2業態・2ターゲット・ビフォーアフターに
- **S06 ベントーグリッド**: 大小カードのモザイクで全体像を先に見せる。多機能・多サービスに
- **S07 エディトリアル**: 段組・罫線・見出し階層で雑誌のように読ませる。読み物性の高い題材に
- **S08 目次型**: 冒頭に章立てを置きアンカーで飛ばす。情報量が多く比較検討される題材に
- **S09 手紙・一人称型**: 店主の語りで最後まで進める。個人の信頼が武器の商売に
- **S10 工程・タイムライン主導**: 流れ（製法・手順・沿革・体験の流れ）を背骨にする
- **S11 一枚ポスター型**: ほぼ1画面に凝縮しスクロール最小。イベント・キャンペーン・単品訴求に
- **S12 縦書き・和組**: 縦書きと「間」を構造の主役に。和の業種・老舗に。様式性が強いため、和の文脈に接続できない題材では接続テストで落として振り直す
- **S13 横スクロール帯**: 縦の流れに横スクロールのショーケースを1本差す。点数の多い見せ物に
- **S14 表・データ主導**: 料金表・比較表を最上位に置く。価格と条件で選ばれる商売に

## ヒーローの型

- **H01 コピー全幅**（視覚要素なし、言葉だけ）
- **H02 2カラム**（文+視覚）——Claudeの最頻出。複数案で使うのは1案まで
- **H03 フルブリード写真+スクリム**
- **H04 極小ヒーロー**（すぐ一覧・本文へ）
- **H05 巨大単語・数字**（1語や1数値を画面の主役に）
- **H06 分割スクリーン**
- **H07 縦書き**（和の文脈に接続できる題材のみ）
- **H08 表・一覧が即出る**

## セクション部品（使い分けの語彙）

交互2カラム/事実の帯/カード列/タイムライン/大きな引用/料金・比較表/FAQ/横スクロール帯/写真ブリード/チェックリスト/ステップ番号/地図+概要/バッジ列。同じ部品は1ページ内2回まで。「数値3連の帯+カード3列」の同時使用はClaudeの癖なので、使うなら意図を言語化する。

## 制約カード（1案に1枚。創造性の強制装置）

- **C01 角丸禁止**（直角だけで組む）
- **C02 書体1つ**（ウェイトとサイズだけで階層を作る）
- **C03 影禁止**（区切りは罫線と余白のみ）
- **C04 無彩色**（黒白グレーのみ。個性は書体と組みで出す）
- **C05 中央揃え禁止**（全セクション左寄せ）
- **C06 ヒーローに写真なし**
- **C07 背景1色で通す**（セクション切替なし、リズムは余白で）
- **C08 数字が主役**（価格・年・件数を最大級のサイズで）
- **C09 罫線グリッド可視化**（表組の美学で組む）
- **C10 余白2倍・要素半分**
- **C11 横幅を絞る**（本文カラム最大640px、一列で読ませる）
- **C12 1スクロール1メッセージ**（各セクションを画面高で区切る）

制約カードは品質を壊さない範囲で守る。破棄する場合は理由を1行書き、代わりの工夫を1つ入れる（無条件破棄は禁止——それをやると結局いつもの形に戻る）。
