# 問いの例(STEP 1〜4)

そのまま全部聞かない。ユーザーの答えで埋まっていない項目だけを、1つずつ、相手の言葉に合わせて聞く。
1行が1回の質問。1回に聞くのは1行だけにし、次の行は答えを受けてから聞く。

## STEP 0〜1: 問題文を作る

- この課題は、誰が何を決めるために解きたいものですか?(上司への報告・予算の判断・自分の次の一手 など)
- 「〇〇」とは具体的に誰(何)のことですか?
- その中に、性質の違う人(もの)が混ざっていませんか?
- 何と比べて「悪い」「多い」と感じていますか?(前年・計画・他部署・業界・競合)
- いつから気になり始めましたか?
- そのころ何か変わりましたか?(価格・体制・制度・季節・競合)
- 全体の話ですか、一部(特定の部署・商品・地域・時期)の話ですか?
- どれくらいの大きさですか?(人数・金額・件数・割合)
- なぜ今、これを解く必要があるのですか?(放っておくと何が起きるか)
- 使える予算・人手・期限はどれくらいですか?
- 依頼に解決策が含まれているとき: その〇〇(解決策)ができたら、何がどう変わる想定ですか?

## STEP 2: 分解の型

| 課題の例 | 分解の例 |
|---|---|
| 売上・収益 | 顧客数(新規+継続)× 購入頻度 × 単価 / 商品別・チャネル別 |
| 解約・離脱 | 利用開始からの経過(初週・1か月・3か月)× 層 / 離脱の直前に何をしていたか |
| 離職・定着 | 入社からの経過 × 部署 × 職種 / 退職理由の種類 |
| 生産性・工数 | 件数 × 1件あたりの時間 / 手戻りの割合 / 待ち時間 |
| 集客 | 認知 → 興味 → 比較 → 申込み の各段の人数と通過率 |

- 分け方が打ち手に結びつくかで選ぶ(分けても誰も何も変えられない軸は捨てる)
- 平均だけを見ない。分布(一部の極端な値が平均を動かしていないか)を見る

## STEP 3: 比較の軸

- 時期: 前年同月・変化の前後
- 層: 新規と既存、若手と中堅、主力とそれ以外
- 場所: 部署・店舗・地域・チャネル
- 計画・目標との差

## STEP 4: 仮説の書き方

```
仮説: <何が原因で、どの指標が、どの層で悪化している>
確かめ方: <見るデータ / 聞く相手 / 小さな試し>
違ったと判断する条件: <この結果なら仮説を捨てる>
手間: <大・中・小>
```

## AI に分析・調査を頼むときの問いの渡し方

同じデータでも、渡す問いで返ってくるものの価値が変わる。

- 弱い: 「このデータを分析して」(何を決めたいのか分からないので、無難な集計が返る)
- よい: 目的・分解の軸・比較対象を添える — 「2回目の購入が減った原因を知りたい。初回購入の月ごと・
  初回に買った商品ごとに分けて、前年と比べて」
- さらに一段上: 見ている指標そのものが適切かを問う — 「売上だけを見ていてよいか。利益や長く使ってくれる顧客の数まで含めて、
  何を問題にすべきか考えたい」
